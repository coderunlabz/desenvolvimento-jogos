Uso de modelo de linguagem

BehaviorTree.cpp foi redigido no Cursor (modelo Grok), a partir do pedido
da fase 4 de 20/10/2026. A semântica de Condition, Action, Sequence,
Selector e BehaviorTree::tick saiu do comentário do próprio .hpp.

BehaviorTree.cpp

Condition: sucesso só se a chave existe no contexto com valor != 0;
chave ausente ou valor 0 = falha; comando vazio.
Action: sempre sucesso; carrega a string do construtor.
Sequence: esquerda para a direita; falha no primeiro filho que falha
(comando vazio na falha); se todos têm sucesso, carrega o último
comando não vazio.
Selector: esquerda para a direita; sucesso no primeiro filho que dá
certo, com o comando dele; falha se todos falham.
BehaviorTree::tick: comando da raiz em caso de sucesso, ou "" se a
raiz falhou. Raiz nula (não coberta pelo .hpp) também devolve "".

Decisões onde o .hpp não diz

Sequence sem filhos: sucesso vazio (nenhum filho falhou; último
comando não vazio é ""). Documentado aqui; o header não especifica.
Se a mesma chave aparece mais de uma vez no contexto, vale a primeira
ocorrência da esquerda para a direita.
